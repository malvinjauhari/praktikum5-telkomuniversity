## 📖 Deskripsi Praktikum
Repositori ini berisi kumpulan kode latihan dan studi kasus untuk **Modul 5** mata kuliah Pemrograman Python di Telkom University. Fokus utama pada praktikum ini adalah pengembangan fungsi modular, pengolahan koleksi data, serta penerapan logika pencarian atau analisis data terstruktur.

## 📁 Struktur Folder
```text
.
├── latihan/          # Kumpulan kode latihan mandiri selama sesi modul 5
├── studi_kasus.py    # Implementasi solusi studi kasus utama Modul 5
└── README.md         # Dokumentasi repositori
```

## 🎯 Topik Pembahasan
* Implementasi fungsi kustom (`def`) untuk memecah logika program
* Pengolahan dan iterasi struktur data (*list*, *tuple*, atau matriks)
* Algoritma pencarian nilai ekstremum, rata-rata, dan frekuensi data
* Penanganan kasus batas (*edge cases*) dan validasi logika tanpa pustaka eksternal

## 🚀 Cara Menjalankan Program
1. Pastikan **Python 3.x** sudah terpasang di sistem operasi Anda.
2. Buka terminal dan arahkan ke direktori proyek ini:
   ```bash
   cd praktikum5-telkomuniversity
   ```
3. Jalankan file program studi kasus:
   ```bash
   python3 studi_kasus.py
   ```
   *(Untuk menjalankan file latihan, gunakan perintah `python3 latihan/nama_file.py`).*
